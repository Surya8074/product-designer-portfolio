# Surya Kiran — Product Designer Portfolio

A cinematic, product-design-focused portfolio built as a lightweight static website.

## Included
- Hero: MAKE / COMPLEX / SIMPLE.
- Selected work: Comski, Genesis, LaundroMart, Teach Grade
- Product design process section
- Responsive layout
- Scroll reveal motion
- Interactive case-study modal
- Dark/off-white visual system with a red accent
- Oswald + DM Sans typography via Google Fonts

## Run locally
Open `index.html` in a browser.

## Deploy
This repository is ready for static hosting such as GitHub Pages, Vercel, or Netlify.

## Personalize before sharing
Replace `hello@example.com` and the placeholder social links in `index.html` with your real contact details.

Add real project screenshots and case-study outcomes when available; the current project visuals are intentionally abstract placeholders so no unverified project screenshots or metrics are invented.
